# Media

Images and videos of the station, used by the READMEs and the manuscript.

```
media/
  logo.png        University of Toronto / Acceleration Consortium logo (top of the main README)
  images/         photos of the station, the Formulator Pen, the parking rack, and renders
  videos/         recordings of runs (tool pickup, dispensing, parking);
                  Formulator_Pen_Demo.gif is the 4x-speed demo shown at the top of the main README
```

Keep videos short or link to an external host; large files bloat the repository
for everyone who clones it.
